# Feeble Frontend Assignment - Hero Section

Pixel-perfect implementation of Feeble's hero section with animations.

## Live Demo

- **Deployed Site:** https://feeble-seven.vercel.app/

## Tech Stack

- **Next.js 15** - React framework with App Router
- **TypeScript** - Type safety
- **Tailwind CSS v4** - Styling
- **Framer Motion** - Animations
- **General Sans** - Custom font

## Installation & Setup
```bash
# Clone the repository
git clone [your-repo-url]
cd feeble-assessment

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build & Deploy
```bash
# Create production build
npm run build

# Start production server
npm start
```


### Key Features
Pixel-perfect dimensions matching Figma specs  
Floating navigation bar with glassmorphism effect  
Animated hero section with birds and clouds  
Smooth entrance animations using Framer Motion  
Fully responsive design  
Clean, maintainable component structure

### Animations
- **Initial Load:** Birds and clouds slide in from bottom
- **After 3 seconds:** Two birds fly across screen simultaneously
- **Continuous:** Bouncing arrow indicator


## Implementation Notes

- All animations optimized for 60fps performance
- Component-based architecture for reusability
- TypeScript for type safety throughout
